# Apply This Pack to an Existing CakePHP 5 Repo

If you already have a working CakePHP 5 application repository and want to improve it into a stronger template repo, copy these files into that repo:

- `.devcontainer/`
- `.vscode/`
- `.github/copilot-instructions.md`
- `config/app_local.example.php`
- `README.codespaces.md`
- `docs/`

Then review:

- `composer.json`
- `config/app_local.php`
- `phpunit.xml.dist`
- `tests/bootstrap.php`

Recommended commit message:

```text
Improve template repo for Codespaces, MySQL, Xdebug, testing, and AI workflows
```
